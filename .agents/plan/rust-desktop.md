# Сервер LiveNote на Rust

## Согласованный результат

Tauri запускает Rust-сервер в своём процессе. MCP доступен по `http://127.0.0.1:4317/mcp` до выхода из LiveNote. У приложения нет отдельного режима запуска из терминала. Node.js нужен только для сборки интерфейса. В пакете нет Node.js, серверных `node_modules` и Chromium.

Если Chromium отсутствует, LiveNote предлагает скачать закреплённую версию. До успешной установки браузера HTTP-сервер и окно заметок не запускаются. После установки LiveNote работает без внешней сети. Rust управляет браузером и использует существующие библиотеки диаграмм в отдельном контексте, который не получает доступ к заметкам.

Поддержка файловых папок сохраняется. Старый режим `--db` и импорт прежних баз не входят в перенос. SQLite остаётся кэшем индекса, который можно восстановить из файлов.

## Контракты переноса

| Что сохраняем | Где описано текущее поведение |
|---|---|
| Исходные байты Markdown и XML, путь как ID, версии, UTF-16 позиции, ссылки и обратные ссылки | `src/server/vaultDocument.ts`, `src/server/vaultProjection.ts`, `src/server/vaultLinks.ts`, `tests/vault-document.test.ts` |
| Правила пути, исключения, блокировка записи, журнал, восстановление и защита от перезаписи чужих изменений | `src/server/vaultFiles.ts`, `src/server/vaultIgnore.ts`, `tests/vault-store.test.ts` |
| Идентификаторы открытых папок, доступ к стартовой папке, несколько папок, завершение после отключения | `src/server/vaultRegistry.ts`, `src/server/vaultIdentity.ts`, `tests/vault-runtime.test.ts` |
| REST-маршруты и тела ответов, проверка Host и Origin, локальная аутентификация, открытие папки и локальная статика | `src/server/rest.ts`, `src/server/app.ts`, `src/server/vaultPicker.ts`, `src/web/api.ts` |
| MCP POST Streamable HTTP, схемы инструментов, `vault_id`, машинные ошибки и результаты | `src/server/mcp/mcpEndpoint.ts`, `tests/mcp-vault-selection.test.ts` |
| SSE `hello`, события обновления, JSON и разделение по папкам | `src/server/sse.ts`, `src/web/events.ts`, `tests/vault-runtime.test.ts` |
| Диагностика и рендер Mermaid, BPMN и draw.io; lint и автораскладка BPMN | `src/server/validator/`, `src/server/services.ts`, `tests/drawio-api.test.ts` |

Вариант с отдельным исполняемым сервером потребовал бы заново связывать два процесса и их завершение. Запуск Rust-сервера внутри Tauri оставляет один владелец жизненного цикла. REST и MCP вызывают один модуль операций с хранилищем. Он использует разбор документов и SQLite-кэш, безопасные файловые операции и проверку диаграмм. Установка Chromium не зависит от заметок и выполняется до открытия хранилища.

## Проверка

- Сравнить ответы Node.js и Rust на одинаковых тестовых папках; проверить запись, конфликт версий, SSE и вызовы MCP.
- Запустить `.app` с пустым тестовым профилем. Проверить предложение установить Chromium, запуск после установки и остановку MCP после выхода. Повторный запуск проверить с установленным браузером без внешней сети.
- Проверить подпись и содержимое пакета. На той же машине прошлый `.app` занимал **749 592 КиБ** по `du -sk`. Измерить новую сборку той же командой.
- Сохранить сборку `.deb` в настройках Tauri. Запуск и установка на Ubuntu отложены.
